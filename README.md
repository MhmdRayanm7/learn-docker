Hands-on exercises and practical implementations from the [Boot.dev Learn Docker](https://www.boot.dev/courses/learn-docker) course, focusing on containerization and DevOps fundamentals.

## Topics Covered

- Docker images and containers
- Container lifecycle and execution
- Persistent storage and volumes
- Docker networking and bridge networks
- Dockerfiles and image layers
- Container debugging and troubleshooting
- Docker Hub and image publishing
- Reverse proxy and load balancing with Caddy

## Practical Implementations

- **Go:** Containerized HTTP server.
- **Python:** Containerized text analysis application.
- **Caddy:** Reverse proxy with round-robin load balancing.

## Tech Stack

Docker, Go, Python, Caddy, Linux.
